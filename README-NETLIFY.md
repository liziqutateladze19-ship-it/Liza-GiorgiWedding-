# Liza & Giorgi Wedding — Netlify version

This version is configured for Netlify Forms.

## Deploy
1. Keep the project in GitHub.
2. In Netlify: Add new project → Import an existing project → GitHub.
3. Select your wedding repository.
4. Publish directory: leave as repository root / default for this static site.
5. Deploy.
6. In Netlify, make sure Form detection is enabled, then redeploy if needed.

## RSVP
Form name: `wedding-rsvp`

Submissions will appear in Netlify → Forms → wedding-rsvp.
You can export submissions as CSV and set email notifications under Project configuration → Notifications → Form submission notifications.
